# RecoverFlow AI

## Intelligent Payment Failure Recovery Agent

RecoverFlow AI is an intelligent payment failure recovery system that analyzes failed payments and recommends appropriate recovery actions.

## Features

- Analyze successful and failed payments
- Calculate revenue at risk
- Identify payment failure reasons
- Calculate recovery probability
- Prioritize payment recovery opportunities
- Recommend recovery actions
- Apply retry limits
- Generate intelligent agent decisions
- Display results in an interactive Streamlit dashboard

## Technologies Used

- Python
- FastAPI
- Uvicorn
- Streamlit
- Pandas
- Pydantic
